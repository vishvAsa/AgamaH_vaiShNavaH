# सूचीपत्रम्

**पृष्ठा**  
१। प्रथमः पटलः ( शास्त्रावतारः ) १-४  
२। द्वितीयः पटल ( पञ्चरात्र स्वरूपनिरूपणम् ) ४-६  
३। तृतीयः पटलः ( वर्जनीयाचार्यलक्षणम् ) ६-७  
४। चतुर्थः पटलः ( आचार्यलक्षणपटलः ) ९-११  
५। पञ्चमः पटलः ( भूतलक्षणपटलः ) ११-१३  
६। षष्ठः पटलः ( भूतशुद्धिपटलः ) १४-१५  
[[16|७ ।]] सप्तमः पटलः ( शंकुलक्षणपटलः ) १५-१७  
८। अष्टमः पटलः ( देवता विभागपटलः ) १८-२०  
९। नवमः पटलः ( बलिदान पटलः ) २०-२२  
१०। दशमः पटलः ( अर्घ्यदानपटलः ) २३-२६  
११। एकादशः पटलः ( शिलाधिवासनपटलः ) २६-३२  
१२। द्वादशः पटलः ( पातालयागपटलः ) ३२-३५  
१३। त्रयोदशः पटल: ( प्रासादलक्षणपटलः ) ३६-३७  
१४। चतुर्दशः पटलः ( देवतासंस्थापन पटलः ) ३७-४२  
१५। पञ्चदशः पटला ( शिलालक्षण पटलः ) ४२-४७  
१६। षोडशः पटलः (वनयागपटल: ) ४७-४८  
१७। सप्तदशः पटलः ( दिक्शान्तिपटलः ) ४९-५४  
१८। अष्टादशः पटलः ( प्रतिमालक्षणपटलः ) ५४-५५  
१९। ऊनविंशः पटलः ( पिण्डिकालक्षणपटलः ) ५५-५६  
२०। विंशः पटलः ( श्रीलक्षणपटलः ) [[१५७|५७]]  
२१। एकविंशः पटलः ( वैनतेयलक्षणपटलः ) ५७-६०  
२२। द्वाविंशः पटलः ( केशवादिप्रतिमालक्षणपटलः ) ६०-६३  
२३। त्रयोविंशः पटलः ( दशावतारप्रतिमालक्षणपटलः ) ६४-६६  
२४। चतुर्विशः पटलः ( [[नवष्यूहप्रतिमालक्षणपटलः|नवव्यूहप्रतिमालक्षणपटलः]] ) ६६-६८  
२५। पञ्चविंशः पटलः ( प्रतिमालक्षणपटल: ) ६९-७०  
२६। षड्विंशः पटलः ( प्रप्रतिमालक्षणपटलः ) ७०-७२  
२७। सप्तविंशः पटलः ( मातृलक्षणपटलः ) ७२-७३  
**२८**। अष्टाविंशः पटल: ( लोकेशप्रतिमालक्षणपटल: ) ७४-७६  
२९। ऊनत्रिंशः पटल ( रुद्ररूपप्रतिमालक्षणपटलः ) ७६-७८  
३०। त्रिंशः पटलः ( गौरीप्रतिमालक्षणपटलः ) ७८-८०  
३१। एकत्रिंशः पटल: ( लिङ्गलक्षणपटलः ) ८०-८२  
३२। द्वात्रिंशः पटलः ( पिण्डिकालक्षणपटलः ) ८२-८४  
३३। त्रयस्त्रिंशः पटलः ( कालपरीक्षापटलः ) ८४-८४  
३४। चतुस्त्रिंशः पटल: ( दिक्पालयागपटल: ) ८४-९१  
३५। पञ्चत्रिंशः पटलः ( कलसाधिवासनपटलः ) ९१-९५  
३६। षट्त्रिंशः पटलः ( स्नपनपटलः ) ९६-१०२  
**३७**। सप्तत्रिंशः पटलः ( अधिवासपटलः ) १०२-१११  
३८। अष्टत्रिंशः पटला (रत्नन्यास पटलः ) १११-११७  
३९। ऊनचत्वारिशः पटल: ( प्रतिष्ठापटलः ) ११७-१२३  
४०। चत्वारिंशः पटलः ( अवभृथस्नानपटलः ) १२४-१२६  
४१। एकचत्वारिंशः पटलः ( बलिदानपटलः ) १२६-१२९  
४२। द्विचत्वारिंशः पटलः ( द्वारप्रतिष्ठापटल : ) १२९-१३२  
४३। त्रिचत्वारिंशः पटल: ( हृत्प्रतिष्ठापटलः ) १३२-१३४  
४४। चतुश्चत्वारिंशः पटलः ( ध्वजप्रतिष्ठा पटलः ) १३४-१४०  

**॥ ० ॥ इति देवताप्रतिष्ठापञ्चकं नाम आदिकाण्डम् ॥ ० ॥**

**प्रतिमा-संक्रान्त टीका** १४१-१७२
