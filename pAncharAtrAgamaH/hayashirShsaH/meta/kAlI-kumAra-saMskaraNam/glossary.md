**Glossary of Terms**

* ***abhaya*** : "Never-fear" hand-pose showing fingers raised upwards with the palm turned to the front.
* ***ādarśa*** : Same as *darpaṇa*, mirror.
* ***akṣasūtra, akṣamālā*** : Rosary.
* ***aṅkuśa*** : Goad.
* ***ardhacandrāsana*** : Seat of half-moon, i.e., semi-circular shape.
* ***āsana*** : Sitting posture, seat.
* ***bāṇa*** : Same as *iṣu* or *śara*, arrow.
* ***brahmasūtra*** : The sacred thread worn by a Brahmin.
* ***cakra*** : Discus, wheel.
* ***carma*** : Shield made of hide.
* ***churikā*** : Knife.
* ***ḍamaru*** : Kettle-drum.
* ***daṇḍa*** : Staff.
* ***dhanu*** : Bow.
* ***dhvaja*** : Flag-staff, standard.
* ***gadā*** : Mace.
* ***gajavyāla*** : A rampant lion (*vyāla*) on a crouching elephant (*gaja*).
* ***galantikā*** : Pitcher.
* ***ghaṇṭā*** : Bell.
* ***gopuram*** : South Indian temple-gateway.
* ***hāra*** : Necklace.
* ***indīvara*** : Same as *kamala* or *padma*, lotus.
* ***iṣu*** : Same as *bāṇa* or *śara*, arrow.
* ***jagamohana*** : Front porch of a temple, a term used in Orissan *śilpa* texts.
* ***jaṭā-mukuṭa*** : Matted hair serving as crown.
* ***kamalā*** : Lotus.
* ***kamaṇḍalu*** : Same as *kuṇḍikā*, a water pot.
* ***kaṅkaṇa*** : Bangle.
* ***kaṅkāla*** : Skeleton (sometimes contextually rendered as skull or bones).
* ***kapāla*** : Skull-cap or skull-bowl.
* ***keyūra*** : Armlet.
* ***khaḍga*** : Sword.
* ***kheṭaka*** : Shield.
* ***kirīṭa*** : Ornamented head-gear worn by Viṣṇu.
* ***kṛpāṇa*** : Sword.
* ***kṛtāñjali*** : A posture showing the palms of the hands joined together for making an obeisance; same as *añjali* or *namaskāra*.
* ***kukkuṭa*** : Cock.
* ***kuṇḍala*** : Ear-ring.
* ***kuṇḍikā*** : A water-pot usually held by a Brahmacārī student.
* ***lāṅgala*** : Ploughshare.
* ***mātuluṅga*** : Citron.
* ***mekhalā*** : Girdle.
* ***mudgara*** : Club.
* ***muṇḍa*** : Head, contextually a decapitated head.
* ***musala*** : Pestle.
* ***nāgapāśa*** : Noose made of serpents.
* ***padma*** : Same as *indīvara* or *kamala*, lotus.
* ***paraśu*** : Axe.
* ***pāśa*** : Noose.
* ***paṭṭiśa*** : A kind of weapon.
* ***prabhā, prabhāmaṇḍala*** : Aureole.
* ***pratimā*** : Image.
* ***prakṣepaṇa*** : Sling.
* ***pustaka*** : Book.
* ***śakti*** : A long spear, usually held by the Hindu war-god Kārttikeya.
* ***śalākā*** : A brush or stick for painting collyrium in the eyes.
* ***śaṅkha*** : Conch, Conch-Shell.
* ***śārṅga*** : Same as *dhanu*, bow.
* ***śayana*** : Reclining posture.
* ***śrīphala*** : A kind of fruit, Indian *bael*, myrobalan.
* ***sthānaka*** : Standing posture.
* ***sūci-mudrā*** : A hand-pose in which the index finger is stretched out, the hand being usually held down.
* ***śūla*** : Trident.
* ***ṭaṅka*** : A stone mason's chisel.
* ***tomara*** : A kind of weapon.
* ***triśūla*** : Trident.
* ***vanamālā*** : A long flower garland usually seen in icons of Viṣṇu.
* ***vajra*** : Thunderbolt.
* ***vara, varada*** : Boon-giving hand-pose showing the hand held down with palm outwards.
* ***vīṇā*** : Lyre.
